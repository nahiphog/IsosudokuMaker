Solution techniques

These are the techniques currently implemented and active in the Generate walkthrough. Each generated puzzle’s technique table reports the steps that actually occur.

TechniqueHow it is used
Snyder notationStep 0 fills every empty cell with its legal candidates in blue. Candidates removed by an ensuing placement are shown crossed out in red for that step.
Naked SingleA cell has exactly one legal candidate, so the walkthrough places that digit.
Hidden SingleWithin a nine-cell marked region or full row, a digit can occupy only one cell, so the walkthrough places it there.
BacktrackingWhen logical singles are exhausted, the verified solution’s digit is tried in the most constrained remaining cell. This is reflected in the difficulty rating.
Single placementThe Custom Build walkthrough reveals each non-given value one at a time from its verified completed grid.
